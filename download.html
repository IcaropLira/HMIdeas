Como instalar
  • Windows: abra o instalador (.exe). Se o SmartScreen avisar, “Mais informações” → “Executar assim mesmo” (o app ainda não tem certificado pago).
  • Linux: AppImage: chmod +x HM*.AppImage e execute — atualiza sozinho. .deb/.rpm: instale pelo gerenciador de pacotes; o app avisa quando houver versão nova.
  • Android: baixe o APK e permita “instalar apps desconhecidos” para o navegador. O app avisa quando houver versão nova.
  • iPhone / iPad: abra o app no navegador (Safari) → Compartilhar → “Adicionar à Tela de Início”.
  • Qualquer sistema: a versão web também é instalável (Chrome/Edge: ícone de instalar na barra de endereço) e funciona offline.
